# Junior Jungle - Interactive Coding Adventure

An educational game platform that teaches kids (ages 4-12) coding and problem-solving through African wildlife adventures.

## Features
- Interactive coding challenges
- African wildlife storytelling
- Gamified learning experience
- Progress tracking and points system
- Age-appropriate content (4-12 years)

## Tech Stack
- **Frontend**: React.js, p5.js, p5.sound
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT

## Project Structure
```
junior-jungle/
├── client/          # React frontend
├── server/          # Node.js/Express backend
└── README.md
```

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- MongoDB
- npm or yarn

### Installation
1. Clone the repository
2. Install dependencies:
   ```bash
   # Install backend dependencies
   cd server
   npm install

   # Install frontend dependencies
   cd ../client
   npm install
   ```

3. Start the development servers:
   ```bash
   # Start backend server
   cd server
   npm run dev

   # Start frontend server
   cd client
   npm start
   ```

## Development
- Frontend runs on: http://localhost:3000
- Backend runs on: http://localhost:5000
